## 👋 Giới thiệu

Xin chào, mình là **Hoàng Hải (h2rhenry)**, nhà phát triển trong cộng đồng **Minecraft server**. Mình viết script và plugin cho server, tối ưu hiệu năng, cấu hình AntiCheat, đồng thời làm web bằng HTML, CSS và JavaScript thuần. Mình cũng biết dùng AI hiệu quả để làm nhiều dự án khác nhau.

- 🧩 Viết **Skript** và plugin **Java** cho Minecraft server
- ⚙️ Tối ưu và quản lý server, cấu hình **AntiCheat**
- 🎨 Làm giao diện web không framework, có chế độ sáng / tối và hai ngôn ngữ
- 🎮 Giải trí với Minecraft và Delta Force
